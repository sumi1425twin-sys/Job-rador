# Job Radar

A simple personal job search website for Finance and HR fresher roles in India.

## Features
- Search jobs by title, company or city
- Filter by Finance or HR, location and match score
- Save jobs you like
- Track application status: Not applied, Applied, Interview, Offer, Closed
- Rule-based job helper (not AI) with quick filters
- Original job links and a "check before applying" note for every job
